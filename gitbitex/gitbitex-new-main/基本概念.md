# 基本概念
## Ticker（行情）  
Ticker（行情）是金融和加密货币交易中的一个核心概念，它表示交易对的实时市场价格和统计信息。
## 吃单 (Taker Order)：
- 主动与订单簿中已有的挂单成交的订单
- 会"吃掉"流动性，因此称为 taker（取者）
- 通常是市价单或以更优价格提交的限价单
## 挂单 (Maker Order)：
- 预先放在订单簿中等待成交的订单
- 提供流动性，因此称为 maker（制造者）

## L1、L2、L3 订单簿深度级别

在加密货币和证券交易中，L1、L2、L3 代表订单簿的不同数据深度级别：
### L1 - 最优行情（Top of Book）
    只包含最好的买卖价格
数据内容：
- 最高买价（best bid）
- 最低卖价（best ask）
- 对应的数量
用途：快速查看当前市场价格，适合行情概览
### L2 - 聚合深度（Aggregated Order Book）
包含所有价格档位的聚合数据
数据内容：
- 每个价格档位的总数量（聚合了该价格的所有订单）
- 买卖双方的完整深度
特点：
- 按价格分组显示
- 不显示具体订单信息
数据量适中
用途：技术分析、订单簿分析、交易策略
###  L3 - 完整深度（Full Order Book）
包含每一笔订单的详细信息
数据内容：
- 每个订单的完整信息（订单 ID、价格、数量）
- 不经过聚合的原始订单数据
特点：
- 数据量最大
- 最详细
- 可以看到市场参与者的具体行为
用途：高频交易、做市商策略、深度分析
